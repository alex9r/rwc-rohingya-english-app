# ml/translation

Phrase-lookup translator: Rohingya ↔ English. No LLM yet; it only returns phrases already in `data/`.

## Use
```python
from ml.translation import translate
translate("Take your pills.", "en->roh")
# {"translation": "Tua*r bori lo.", "status": "ok", "confidence": 1.0}
```
- Directions: `"en->roh"` or `"roh->en"`
- Status: `ok`, `uncertain` (no good match, translation is `None`) or `failed` (bad input)
- Confidence: 0–1 match score, not a correctness score

## Test
Run from the repo root:
```
python -m ml.translation.run_tests --reverse
python -m ml.translation.run_tests --file a.csv b.json
```
Add tests to `tests.csv` (`english, rohingya, reverse`). Leave `rohingya` blank to expect `uncertain`. Misses go to `failures.csv`.

## Phrase data
- `data/rohingya_phrases_38.json`, `data/rohingya_greetings_40.json`: core phrase sets
- `data/collections/`: groceries, transportation, pharmacy, employment and everyday
  collections (72 phrases, 35 alternative translations), every one a Gamayun kit5k sentence.
  Generated by `build_collections.py`; scored by `review_phrases.py` (Gamayun + IOM check,
  confidence 0.95 / 0.70 / 0.50). Don't hand-edit them: add the kit5k line number to
  `SPEC` in `build_collections.py` and rerun.

Test the collections, including their alternative translations:
```
python -m ml.translation.run_tests --reverse --file ml/translation/data/collections/*.json
```
